### 🧭 A little about me

I'm a Software Developer based in Chennai, working at the intersection of **enterprise systems, government e-governance platforms, and workflow automation**. Over the last 3+ years, I've helped digitize processes that used to run on paper and phone calls — ERP systems, transfer management portals, examination platforms, and disaster-response tools used by real institutions and real people.
